# 软件指南生成器

macOS 原生 App：输入软件名称和功能要求，自动规划界面、调用模型生成界面示意图、撰写说明文字，导出 Word / PDF / TXT 指南；配置自己的代码来源后也能排版代码文档。支持单个项目精修和批量处理。

[下载](https://github.com/deepfry666/ruanzhu-guide/releases) · [快速入门](docs/快速入门.md)

> 应用里称为「截图」的图片是 AI 生成的界面示意，不是实际运行软件的截屏，也不能证明功能已实现。文字、日期、代码来源和导出材料都需要人工核验。

## 功能

| 工作 | 功能 |
| --- | --- |
| 从需求到初稿 | 规划界面，生成配图，用看图模型验收并抄录图中文字，撰写说明，可附加设计说明 |
| 逐屏修改 | 图片和文字并排编辑；单屏改图、只改文字、查看与恢复历史版本 |
| 交付文件 | 导出指南 Word / PDF / TXT；配置代码来源后生成代码文档 |
| 批量处理 | 批量新建、按名单选择、只重写文字、全部重做、批量更新代码材料与导出 |
| 追踪过程 | 项目进度、调用记录和统计；「已提交」标记让项目保持只读 |

## 使用前准备

- **系统**：macOS 26 或更高，arm64 + x86_64 通用包。
- **模型服务**：自备生图线路和大模型 API。下载应用不含模型额度，生图、规划、验收、写文字都可能由服务商计费。
- **LibreOffice**：指南 PDF 转换需要另外安装。
- **代码与字体**：代码模板和商业字体不随安装包提供。

安装包采用 ad-hoc 签名，首次打开可能需要在「系统设置 → 隐私与安全性」里放行。之后可在软件里「检查更新」在线升级。

## 数据

- 项目默认保存在 `~/Desktop/软件指南生成`，可在设置里更改。
- 设置、调用记录和密钥保存在 `~/Library/Application Support/软件指南生成器（原生版）`。
- AI 步骤会把所需文字或图片发送给你配置的模型服务商。不要提交 API 密钥、应用数据目录或调用日志。

## 从源码构建

需要 Xcode 27（macOS 27 SDK）。

```bash
cd native
scripts/build-app.sh --zip     # 生成 dist/软件指南生成器.app 和 zip
```

也可以用 Xcode 打开 `native/ManualStudio.xcodeproj` 开发。发版：`native/scripts/release.sh <版本号> [更新说明文件]`。
